# Architecture / working contracts

Development modules are bundled with esbuild into an offline inline script. Simulation is independent of DOM and WebAudio; fixed 60 Hz ticks, seeded PRNG, explicit menu states stop the simulation. Canvas logical resolution 960 × 540; centered player world camera. Original procedural pixel sprites and synthesised music; no extracted assets.

## Module contracts (iteration 1)
- `src/data/content.js`: exports CONFIG, CHARACTERS, WEAPONS, PASSIVES, ENEMIES, STAGES, EVOLUTIONS. Definitions have id, name:{ja,en}, description:{ja,en}. One benchmark character/stage until comparison gate passes.
- `src/gameplay/engine.js`: exports Engine. `new Engine({seed=1,character='antonio',stage='forest',powerups={},auto=false,endless=false}={})`. `step(dt=1/60,input={x:0,y:0})`; `choose(id)`; `openChest()`; `snapshot()`; `give(id,level=1)`; `debug(action,value)`.
- Engine public data: state `playing|levelup|chest|dead|won`, time(seconds), tick, player:{x,y,hp,maxHp,level,xp,nextXp,facing,stats}, enemies:[{id,x,y,hp,maxHp,r,type,flash}], pickups:[{x,y,type,value,r}], projectiles:[{x,y,type,r,...}], effects:[{x,y,type,life,maxLife,dir,range,...}], texts:[{x,y,value,life}], weapons:{id:level}, passives:{id:level}, choices:[{id,kind,level}], chestRewards:[{id,kind,level}], kills, gold, damage, telemetry, metrics, rng, options:{invincible,freezeAI,collisions,hitboxes,grid}. `onEvent(type,data)` callback assigned by app.
- `src/render/renderer.js`: exports Renderer; constructor(canvas); `draw(engine,settings={})`; `resize()`; public `stats` render metrics. World origin at center, scale = 1 logical pixel/unit, characters ~22px tall. Pure procedural original pixel art; cached sprites and terrain tiles. Does not implement menu DOM or mutate engine.
- `src/services/audio.js`: exports AudioService with `unlock()`, `event(type)`, `update(settings)` (master,music,sfx 0..1), `tick(dt)`, `stop()`; bounded voices and original procedural BGM.
- `src/services/save.js`: exports SaveService with load(), save(data), export(data), import(text), defaultSave(). Format {saveVersion:1,gold:0,totalKills:0,runs:0,bestTime:0,powerups:{},unlocks:{},collection:[],settings:{language:'ja',master:.6,music:.35,sfx:.6,damageNumbers:true,shake:true,flashes:true,performance:false,gamepad:true}}.
- `src/ui/ui.js`: exports UI; `new UI(root,app)`; `render()`, `updateHUD()`. app fields `screen` (main/characters/stages/powerups/collection/unlocks/secrets/options/game/pause/results/lab), `engine`, `save`, `audio`, `fps`, `debugVisible`. app methods `navigate(screen)`, `startRun(opts={})`, `resume()`, `quitRun()`, `choose(id)`, `chestContinue()`, `setSetting(key,value)`, `buyPowerup(id)`, `debug(action,value)`, `exportSave()`, `importSave(text)`. `app.language` getter; `app.lastResult`; `app.selectedCharacter`, `app.selectedStage`; `app.lab` config. UI owns DOM menus and HUD, renderer owns world. UI can import content.js, no circular app imports. `ui.handleAction(action)` handles confirm/cancel/up/down/left/right. Must not claim unavailable content implemented.
- `src/main.js`: app state machine, Input abstraction, browser loop, debug bridge `window.__VS` exposing {app,Engine,runFrames(n,input),snapshot(),start(opts),debug(action,value)} for automated browser checks. `?debug=1` enables developer panel. F3 toggles debug.

Known fidelity blockers are explicitly tracked; no unverified reference values are labelled confirmed. Existing checkout is isolated: do not create worktrees.

Replay records exact input changes and menu decisions on simulation ticks; `ReplayRunner` reuses deterministic steps. Recording is capped at 260,000 events (more than one hour of 60Hz changing inputs); subsequent events set an explicit truncation flag. Truncated recordings are rejected for exact playback, while gameplay continues. Debug warp on the application bridge is sliced into at most 8ms of simulation work per animation callback; laboratory inputs and developer spawn loops are bounded and finite.
