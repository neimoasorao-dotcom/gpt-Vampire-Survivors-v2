# Progression, unlocks and modes

Persistent save schema requirements: version, gold, runs, kills/best time, characters/unlocks, powerups, collection, relics/arcanas/secrets/mode flags and settings. Guard malformed/partial/old saves and import with type/bounds validation.

Original unlock thresholds, prices, relic routes, secrets and current menu catalogue: **unknown**. Engineering achievements may be measured against local runs but must not masquerade as exact original unlocks.

Required eventual modes: Hyper, Hurry, Inverse, Endless and Limit Break; each has distinct timer/modifier/end behaviour requiring research. A debug speed multiplier is not Hurry; disabling the end is not a full Endless reconstruction. Completed-run gold and discoveries must survive reload and browser restart; file:// storage support must be tested on the packaged artifact.


## Evidence discipline

Status vocabulary: `confirmed` = read authoritative evidence, `measured` = reproducible direct measurement, `cross_checked` = independent supporting sources, `estimated` = provisional engineering assumption, `unknown` = unavailable. An attempted URL is not evidence of its contents. Current reference source access is denied; source-specific values below are hypotheses, not extracted measurements. See `evidence.json`, `estimated_values.md`, and `reference_target.md`.
