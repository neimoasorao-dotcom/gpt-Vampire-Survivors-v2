# Audio and timing

Original music and protected sound files are not extracted or redistributed. Reconstruction uses original synthesized voices and composition. This satisfies audible feedback but cannot establish audio fidelity.

Capture/measure reference attack cadence, relative hit/XP/chest volume, pitch ranges, reveal interval, evolution accent and menu response after lawful source access. Needed event coverage: menu/confirm, XP, level, attack, hit, crit, kill, gold, chest, evolution, player hit, death/results and BGM.

Architecture: separate master/music/SFX gain, bounded concurrent voices, short release ramps, first-user-gesture AudioContext unlock and supported resume. Verify suspended context and mute/gain changes; an audio graph existing is not proof audible output reached speakers.


## Evidence discipline

Status vocabulary: `confirmed` = read authoritative evidence, `measured` = reproducible direct measurement, `cross_checked` = independent supporting sources, `estimated` = provisional engineering assumption, `unknown` = unavailable. An attempted URL is not evidence of its contents. Current reference source access is denied; source-specific values below are hypotheses, not extracted measurements. See `evidence.json`, `estimated_values.md`, and `reference_target.md`.
