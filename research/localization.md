# Localization

Japanese and English are required from first implementation. Labels use keyed dictionaries or localized data values; Japanese fallback stack includes Yu Gothic UI, Yu Gothic, Meiryo, sans-serif. Exact official Japanese names and descriptions are **unverified** until Japanese reference capture/source review.

Maintain local candidates separately from confirmed official terms. Antonio, Whip, Mad Forest and Bloody Tear names may be shown as recognizable English alongside Japanese candidates; do not label those candidates official localization. Test line wrapping, numeral widths, text overflow, button focus and in-run language switch at all requested resolutions.

A fallback font present on Linux does not prove Windows typography. No protected font is copied; system fallback is deliberate and documented in asset manifest.


## Evidence discipline

Status vocabulary: `confirmed` = read authoritative evidence, `measured` = reproducible direct measurement, `cross_checked` = independent supporting sources, `estimated` = provisional engineering assumption, `unknown` = unavailable. An attempted URL is not evidence of its contents. Current reference source access is denied; source-specific values below are hypotheses, not extracted measurements. See `evidence.json`, `estimated_values.md`, and `reference_target.md`.
