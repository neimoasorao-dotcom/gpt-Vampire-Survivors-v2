# Gameplay model

Working hypothesis (`estimated`): movement-only control with automatic attacks; enemy pressure, ground XP, upgrade pauses, periodic boss chests and a timed run create the core loop. A 30-minute boundary and post-boundary Reaper encounter are the requested benchmark, not a statement verified against the current patch.

Measure after source access: first 30 seconds, movement screen-distance/second, first level timing, inventory growth, kill count and XP slope at 1/3/5/10/15/20/25/28/29/30 minutes. Keep powerups, character, build and mode in every sample. Compare distributions across independent sources rather than matching one video. Avoid retuning enemy counts to improve FPS.
